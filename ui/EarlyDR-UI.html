How a patient is classified

Input → model → referral, in three steps

STEP 1 — INPUT

Fundus photograph

A single retinal image is cropped to the circular field of view, resized, and contrast-enhanced (CLAHE) so lesion patterns are consistent regardless of camera or lighting.

STEP 2 — MODEL

5-class severity grading

A CNN/ViT/MobileNet backbone outputs a probability for each of the five ICDR grades. The class with the highest probability is the predicted grade; the full distribution is kept visible.

STEP 3 — OUTPUT

Referral decision

Grades collapse into one of three actions — routine, follow-up in 3–6 months, or refer to a specialist — so a non-specialist worker can act on the result immediately.

Project overview

Catching diabetic retinopathy at the stage it's still treatable.

EarlyDR is a deep-learning screening assistant for diabetic retinopathy (DR) — built for low-resource clinics that have a fundus camera but no on-site retina specialist. It grades a retinal photograph on the standard 5-point severity scale, then translates that grade into a plain referral action a non-specialist can act on immediately. Unlike most published DR classifiers, which optimize for overall accuracy, EarlyDR is tuned specifically to catch Mild and Moderate cases reliably — the stages where a referral can still prevent vision loss.

SDG mapping

Good health and well-being

3SDG
Reducing preventable blindness from a non-communicable disease
Diabetic retinopathy is a direct complication of diabetes and a leading cause of preventable blindness. EarlyDR supports SDG 3.4 (reducing disability from NCDs) and SDG 3.8 (access to essential health services) by giving low-resource clinics a first-line screening pass, so scarce ophthalmologist time is reserved for confirmed, high-risk referrals.

Model comparison

One dataset, three architecture tracks

Track 1

CNN backbone

ResNet-50 / EfficientNet, transfer-learned. The high-capacity baseline the other two tracks are measured against.

Optimized for: accuracy
Track 2

Vision transformer

ViT-Base/16, fine-tuned with attention-map explainability. Tests whether global attention beats local receptive fields.

Optimized for: representation
Track 3

MobileNet, quantized

MobileNetV2/V3 with INT8 post-training quantization. Built to run inference on basic clinic hardware.

Optimized for: deployability
Novelty

What's different about this approach

01Early-stage-first evaluation — Mild/Moderate recall is the primary metric, not aggregate accuracy, using class-weighted loss and per-class reporting.
02Three-way architecture comparison — CNN, ViT, and MobileNet trained on identical data and metrics, producing an explicit accuracy-vs-cost curve.
03Edge deployability as a constraint — the MobileNet track is quantized specifically to run on low-cost clinic hardware, not added as an afterthought.
04Cross-dataset robustness testing — training on one dataset and validating on another to explicitly measure domain-shift, rarely reported at this level.
